# 打开网址（me.open-url）

在 Win顺 的搜索框里输入一个网址，列表里立刻出现一行，按 Enter 用默认浏览器打开。不用先输入关键字。

## 用法和示例

| 输入 | 结果 |
|---|---|
| `https://www.deepseek.com/` | 打开 `https://www.deepseek.com/` |
| `www.deepseek.com` | 打开 `https://www.deepseek.com`（没写协议，补 https） |
| `deepseek.com` | 打开 `https://deepseek.com`（常见后缀的裸域名，可在设置里关闭） |
| `localhost:3000`、`192.168.1.1` | 打开 `http://…`（本机和内网地址补 http） |
| `https://中文.com/路径` | 域名自动转成浏览器认的 punycode |
| `url 任意域名.xyz` | 用关键字 `url` 明确表示这是网址，裸域名不限后缀 |

- 网址行推送到“全部”里，分数设为 95（和应用同一尺度），通常排在靠前的位置，实际位置以 Win顺 的混排为准；Ctrl+C 复制网址。
- 单独输入 `url`（后面加空格）会显示一行提示；输入不是网址时显示“这不是可识别的网址”。自动识别时，不是网址就什么都不出，不干扰平时的搜索。
- 只认 `http` 和 `https`。`ftp://`、`file://`、`javascript:` 以及带账号密码的网址（`https://user:pw@…`）不识别。
- 不带协议、不带 `www.` 的裸域名只认常见后缀（com、net、org、cn、io、ai、dev、app……），避免把 `main.py`、`readme.md`、`run.sh` 这类文件名当成网址。需要别的后缀时用 `url ` 关键字，或写上 `https://`。

## 设置

- **识别不带 http 的域名**（默认开）：关掉后，只有 `http(s)://` 或 `www.` 开头的输入会被识别。

## 运行依赖

需要 Python 3（python.org 版本即可），无第三方库。找不到 Python 时，插件卡片上会写“需要 Python 3”并给出下载链接。

自己的测试：`python -m unittest -v test_main`（在插件目录里运行）。

## 权限

**不申请任何权限。** 脚本只做字符串检查；打开浏览器是 Win顺 按结果里的 `open.url` 自己执行的，而 `http/https` 网址本来就不需要 `processes` 权限。脚本不联网，也不请求网站图标（图标用本地字形，避免因为你输入的每个网址向对方站点发请求）。

## 数据位置

不读写任何文件，也不使用数据文件夹。

## 失败处理

- 脚本异常时，错误写入 `%LOCALAPPDATA%\WinShun\plugins.log`，退出码非 0，Win顺 底栏提示失败，不返回伪造的结果。
- 设置值损坏时回退到默认值，不影响识别。
- 关键字 `url` 如果和别的插件冲突，用户的设置优先；在设置里改一个关键字即可，自动识别不受影响。

## 已知限制

- 触发用的正则只负责把明显不是网址的输入挡在门外，最终判断由脚本做。所以输入 `main.py` 这类长得像域名的文件名时，会短暂起一次 Python 进程，结果是空的。
- 以中文等非 ASCII 字符开头、且不带协议的域名（如 `中文.com`），自动识别不会触发，请写 `https://` 或用 `url ` 关键字。
